Mandatory Fields Visual Indicator

Clear, modern, and beautiful visual indicators for all required fields in Odoo forms. Eliminate user confusion, speed up data entry, and stop annoying validation errors before clicking save!

✓ Odoo 18.0 ✓ Odoo 17.0 ✓ Odoo 16.0 ✓ Community & Enterprise

Why Do You Need This Module?

Odoo's default styling makes required fields barely noticeable until users hit Save and get blocked.

Without This Module

Frustrating Validation Errors

Users have to guess which fields are mandatory. Submitting forms often triggers validation popups, slowing down workflows and causing frustration during fast data entry.

With This Module

Crystal Clear Guidance

Every required field stands out immediately with your chosen visual indicator (Red asterisk, sleek accent bar, soft tint, or pill badge). 100% intuitive and error-free.
