# Mandatory Fields Visual Indicator

Tired of frustrating validation popups when saving forms? This module provides clear, modern, and customizable visual indicators for all required/mandatory fields across Odoo backend form views.

### Key Features
* **8 Distinct Visual Indicator Styles:** Choose from Left-Accent Bar, Soft Pastel Tint, Required Badge, Indigo Glow, Coral Pulse Dot, Executive Gold, Glassmorphism, and Classic Asterisk.
* **Instant Configuration:** Switch visual indicator styles on the fly via **Settings > General Settings** without touching code or restarting services.
* **Intelligent Dynamic State Handling:** Automatically disables indicator highlights when fields are in `readonly` or view-only mode.
* **Zero Database Bloat:** Implemented via clean SCSS styling and lightweight session info injection.
* **Broad Compatibility:** Works seamlessly across standard and custom Odoo form views, many2one relations, inputs, and textareas.
