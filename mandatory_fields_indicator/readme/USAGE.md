To use this module:

1. Open any form view in Odoo (e.g. Sales, Purchase, Inventory, CRM, Accounting, or custom models).
2. All mandatory/required fields will immediately display the configured visual style (such as left-border accent bar, pastel tint, or floating required badge).
3. As soon as a field is filled or toggled to readonly, the styling adjusts dynamically to keep forms clutter-free.
